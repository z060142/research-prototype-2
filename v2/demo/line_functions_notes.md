# line_functions.csv：說明與裁定

`line_functions.csv` 是 D01 整章重寫用的規格。每一列對應一個字串 ID，說明這句必須傳達什麼。目前 379 列，依章節出現順序排列，其中一列 `SCR_D01_S03_L002A` 是新增行，字串 CSV 等定稿時再加。

欄位：
- `category`：這句的功能分類。
- `must_convey`：必須傳達的事實，一行一點。
- `constraints`：不能說破的事、必須保留的稱呼與口頭禪、與其他 ID 的對應關係和播放條件。

純氣氛、沒有功能的句子不列。系統訊息（SYS_）、標籤、短標不在範圍內。

下列事項都已由企劃裁定，並已寫進該列的 constraints（以「裁定：」開頭）。事實與條件也已同步改進 `v2/11_demo_chapter.md`。中文、英文字串都等整章重寫時再改；唯一的例外是 S03 標題。
