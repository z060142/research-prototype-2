# line_functions.csv：說明與待決事項

`line_functions.csv` 是 D01 整章重寫用的規格。每一列對應一個字串 ID，告訴重寫者這句必須傳達什麼。共 378 列，依章節出現順序排列。

欄位：
- `category`：這句的功能分類。
- `must_convey`：必須傳達的事實，一行一點。
- `constraints`：
  - 不能說破的事；
  - 必須保留的稱呼與口頭禪；
  - 與其他 ID 的對應關係與播放條件。

純氣氛、沒有功能的句子不列。系統訊息（SYS_）、標籤、短標不在範圍內。

整理時發現下列現行資料與規則不一致或可能有問題。規格裡已在該列的 constraints 註明處理方向，但下列各項需要企劃裁定。

## 數字與事實

- **APR_D01_02_LINE**：時間算法不成立。
  - 原句說「從 9:40 走到 10:48，走了 1 小時 8 分，往回推是 11:02」，照這樣算，現在只是半夜 00:10。
  - 改寫時應改用「慢了多少」往回推：在實際 11:02 時鐘面是 9:40，所以一直慢 1 小時 22 分。
  - 推回的時刻 11:02 必須保留。
- **1.3 時序第 2 點 vs HS_D01_13_DESC、PN_D01_4_TEXT**：誰整理書房說法不一。
  - 1.3 寫「塞德里克整理書房時先看到附錄」。
  - 調查點和筆記則寫「艾琳整理，少爺站在門口」。
  - 另外，說法 10B 說「他一直待到整理完」，但調查點和筆記都沒寫這件事。
- **SCR_D01_S09_L002**：寫「關閉」煤氣總閥，真相是「關小」。

## 一句話要對應多種情況

- **CARD_D01_L2_DOWN**：01A 和 06A 截斷 L2 後都播這句，但內容只回應 01A 的「真正的鑰匙」。
- **CARD_D01_L4_DOWN**：04B 和 07A 截斷 L4 後都播這句，但內容只回應 07A 的「廚房裡一直有人」。
- 上面兩句要嘛寫成兩種截斷都適用，要嘛替另一個說法另寫一句 CUT_ 反應。
- **EXCL_*_CATCH**：
  - 現行台詞都假設某一句先說。
  - 實際上哪一句都可能先說，矛盾在後說的那一句觸發。
  - 改寫要不分先後，或者每組做兩個版本。
- **LINK_D01_09A_10A**：雙向承接。
  - 它取代 09A 時，必須說出艾琳的身世，否則不會觸發公開私事。
  - 它取代 10A 時，必須說出吸墨紙上的「一半遺產」。
- **LINK_D01_02A_03A**：現行句子漏了 03A 的事實（蠟油、空燭台）。
- **CARD_D01_U2_TELL**：半句「錢……」不是 U2_STATE 的開頭。
- **CARD_D01_U2_CATCH**：用到四百鎊、月底、遺產少一半。這些只有帶了 E08／E10 才知道，建議改以他自己承認欠錢為主。
- **CARD_D01_K1_STATE 與 SCR_D01_S07_L010**：應為同一句，現行差一個字。

## 條件與版本

- **BEAT_D01_REFUTED_1/2**：備註寫「06B 或 04C 被駁倒」。但 04C 不會被駁倒（§5.2、debate_data.json），實際只有 06B 會觸發。
- **SCR_D01_S10_L002**：無條件播放。
  - 但布里格斯回來的理由只有說過 07A／07B 才會知道。
  - 路線 B 會和 L007「沒人解釋布里格斯為什麼在屋裡」同時出現。
  - 建議加上條件：說過 07A／07B 且勝利。
- **SCR_D01_S10_L001／L004／L006**：敗北時也會播。
  - L006「我們抓對了人」在敗北時不成立。
  - L001、L004 在敗北時不能寫他被捕。
- **SCR_D01_S10_L005**：「有一半是她自己編的」只適合靠詭辯取勝的情況。
  - 40～69% 也可能來自誠心但錯的說法，或缺了關鍵證物。
  - 路線 D 就是 60% 的敗北。
- **SCR_D01_S10_L008**：「我們讓他回家了」只適合勝利，但 06B 在敗北時也可能說過。
- **SCR_D01_S07_L017、S08_L012**：都把失敗歸因於留下的證物，但敗北不一定有證物被留下。
- **SCR_D01_S08_L011**：亞瑟後悔沒拆筒子，但筒子可能已經鑑定過。
- **SCR_D01_S08_L001**：每次勝利都播，所以要在沒提過艾琳身世時也說得通。

## 必須保留的引用與伏筆

- **S03_L010 → S03_L014**：「鄉下迷信」要逐字相同。
- **S01_L002 → S08_L007／L008**：警督的「鼻子」。
- **S02_L008 → S08_L010**：嘴上越說不信的人。
- **S10_L007**：「說了會害到人」要和 HS_D01_26_DESC 布里格斯的話一致。
- **FOG_D01_1**：必須保留「煤氣味」。路線 B 他的反駁會接這個詞。
- **FOG_D01_3**：
  - 不要依賴前一句提過「刮痕」。
  - 也不能碰到證物。
  - 暗藏的線索是鞋跟磨損，指向傭人樓梯。
- **怕鬼**：整章都只能用動作和物件暗示（護身符、床頭燈、別過臉、站在門口、馬蹄鐵），不能明說。
- **附錄與艾琳的身世**：塞德里克不能透露他早就看過附錄，或早就知道受益人是艾琳。
