## 1. 設計目標

1. 【定】同一件證物可以有不同詮釋；玩家怎麼使用證物，決定他能提出什麼推理。
2. 【定】贏不代表掌握真相；可以靠詭辯勉強獲勝，也可能贏得不體面而失去信任。
3. 【定】這些取捨發生在每一回合的出牌裡，不是結算畫面才告知。
4. 【定】推理鏈逐回合建立，每回合只有一個明確的論證主體；不再預先組鏈、一次打出一段。
5. 【定】雙方同時決定行動，再結算。
6. 【定】論破是攻防的高潮，不是勝利；一次只有一方被論破；論破後對手可能還有最後一張牌。
7. 【定】每場論戰依案件專門設計，不要求系統對所有組合都有敘事反應。

## 3. 證物與說法

### 3.1 說法的資料

每個說法有下列欄位：

| 欄位 | 內容 |
| --- | --- |
| 文本 | Sherefox 說出這個說法的台詞（主張句） |
| 爭點 | 屬於哪一個爭點 |
| 解鎖條件 | 玩家要先知道什麼，這個說法才會出現在清單上（例：鑑定過鐘，才能說「鐘慢了三分鐘」）。沒有條件則一律出現〔R-07〕 |
| 相容條件 | 一份「與此說法衝突的資訊」清單（證物、鑑定結果、觀察、對手說溜嘴的話） |
| 真偽 | 這個說法是否符合真相。對玩家隱藏 |
| 互斥 | 與哪些其他說法互相矛盾 |
| 可破解 | 這個說法能駁倒對手的哪些論點 |
| 對手能否駁倒 | 對手能用哪一件撿來的證物，或哪一句他已公開說過的事實，駁倒這個說法；附一句「駁倒＋嫁禍」台詞。鑑定結果對手拿不到〔R-05〕 |
| 心理作用 | （選填）對特定對手的壓力／罪惡感／怒氣加減 |
| 私事 | （選填）是否公開了當事人不必被公開的私事 |

### 3.2 正論與詭辯由「玩家知道什麼」決定【提】

* 說法的衝突清單中，沒有任何一項是玩家已知的 → 顯示為**正論**。
* 有任何一項是玩家已知的 → 顯示為**詭辯**（玩家是明知故說）。
* 「已知」＝玩家帶走的證物、做過的鑑定、看過的觀察。沒帶走、沒鑑定的不算已知。
* 對手說的話不會自動成為已知（否則會洩漏那句話的真假）。只有兩種情況算：玩家用「抓住他的話」接上（6.5），或他在駁倒玩家時親口說出〔R-06〕。
* 因此玩家可以誠心打出一個不符合真相的正論。這就是「鏈結實但方向錯」：系統當它是正論，對手也只能用玩家不知道的資訊去打它。
* 一個說法在論戰途中可能由正論變成詭辯（例如對手說溜嘴，玩家因此「知道」了）。已經打出的節不回溯；之後再用才算詭辯。
* 心理牌（例：通靈板）沒有任何正論說法，所有說法都是詭辯【定：通靈板算詭辯】。心理牌的說法也要標爭點〔R-30〕。心理牌接上的節在對決表上照詭辯結算（會被拆穿），但**不計入裂紋**，代價在社會聲譽與真相度：它的說法真偽為假，第 9 節照扣（用迷信嚇出真相，不算推理出真相）〔V-08〕。單張心理牌對單一數值的增量不超過該對手門檻的 60%〔V-16〕。否則它一定讓對手在殘局還手，等於陷阱〔模擬〕。

### 3.3 詮釋的時機【提】

* 詮釋在論戰中進行：出牌時選證物，再選說法。
* 調查時不做選擇題。證物清單上每件證物可以留一句「私下的看法」（從該證物的說法中擇一，或留空），隨時可改，沒有代價，也沒有效果，只是玩家的筆記；論戰選說法時預設停在這一項。
* 線索板畫面移除。

### 3.4 重複使用與矛盾【提】

* 同一件證物可以重複使用【定】。同一個說法站在鏈上時不能再接一次；被打掉後可以重提（重提的論證 ×0.5）。站在鏈上的說法仍可以拿來反駁〔R-35〕。被對手駁倒的說法本場作廢，但作廢不回溯：之前用它得到的成果保留〔R-21〕。
* 說法與自己公開紀錄中的某句話互斥時，選項按鈕顯示**紅色裂紋**。可以選，代價：
  * 可信度立即 −10。
  * 舊的那一節若還站著，立刻失效移除。
  * 新的這一節帶 1 道裂紋。用反駁選到互斥的說法時沒有新節，裂紋記在公開紀錄〔V-06〕。
* 不遮蔽矛盾選項。

### 3.5 製作規範【提】

* 每個爭點至少要有一個詭辯說法，否則詭辯反駁在那個爭點上無牌可用〔V-13〕。
* 中後期每件證物盡量有一個「沒鑑定時看起來合理、其實是錯的」說法，這是「方向錯」的戲的來源。

## 4. 調查（v2 只規定與論戰相接的部分）

1. 【定】每次調查能帶走的證物數量有限。【提】上限由各章自訂，原則是現場可參戰證物數的三分之二左右，並取「通過 4.5 檢查、且最差帶法下謹慎打法勝率仍過半」的最緊數字（把對手能撿的證物全留下，本來就該打得辛苦；示範關卡最差帶法 58%）（Ch.1 教學章不設限）。只少帶 2 件時幾乎沒有取捨〔示範關卡：13 件帶 9 件〕。
2. 【定】沒帶走的證物可能落入對手手中。【提】每件證物另有一欄「對手的用法」；這一欄要註明他把它當謊言還是事實來用〔R-29〕。有這一欄且被留下的證物，進入對手的牌庫。對手最多撿 2 件。玩家離開現場前能看到「留下的清單」，不會顯示哪些會被撿。
3. 【提】鑑定次數有限（每章由數值表定，原則上少於可鑑定的證物數）〔R-22〕。鑑定（亞瑟的醫療／機械）不改變證物本身，而是讓玩家「知道」更多：鑑定結果會進入說法的相容判斷，可能把一個原本的正論變成詭辯，也會解鎖新的說法。
4. 【定】對手的個人弱點與性格靠調查對手本人、日常相處得知。【提】調查點新增「人物」類：得到的不是證物，是一條人物筆記（弱點或性格線索），不佔攜帶名額。能戳中弱點的道具（心理牌）要佔名額。
5. 【提】防卡關：每場論戰必須保證，任何合法的帶法都至少有一條不靠詭辯的獲勝路線，而且手上至少有一個能截斷對手某個謊言的正論（否則雖然有解，謹慎的玩家多半還是會輸；檢查工具把這種帶法標為 WEAK）〔模擬三〕；差別只在漂亮程度（能否乾淨論破、是否拿到黃金線索）。這個保證只涵蓋「帶滿上限」的帶法；玩家刻意少帶時，整理畫面會由亞瑟提醒還有空位，後果自負〔模擬二：Ch.2 的 183 種帶滿帶法全數通過，少帶的 1602 種中有 81 種無解〕。帶法與鑑定的組合由 `v2/sim/check45.py` 自動檢查，不靠人工〔審查 4.3〕。

## 5. 論戰的構成

### 5.1 雙方各有

* 可信度（上限：玩家 100／140／150 依前中後期〔模擬二〕；對手依數值表）。
* 推理鏈與公開紀錄。
* 連擊數：連續成功接上節的回合數。沒接上（被擋、打迷糊仗、反駁）不歸零也不增加。玩家在被拆穿、被駁倒、被論破時歸零；對手在立論被截斷、鏈上的節被拆台、被論破時歸零〔R-02〕。【提】
* 對手另有：手牌、三個心理數值、性格表。

### 5.2 對手的手牌【定】

| 類別 | 內容 | 何時打出 |
| --- | --- | --- |
| 謊言 | 與真相不符的論點 | 一般 |
| 有利的事實 | 真的，且對他有利 | 一般 |
| 不利的事實 | 真的，但對他不利 | 只在心理失常，或有利的牌與謊言用盡時 |
| 撿來的證物 | 玩家留下的證物（依「對手的用法」） | 一般；也可留作最後一張牌 |
| 最後一張牌 | 每個對手 0～1 張劇本指定的殺手鐧 | 被論破之後 |

* 系統不標示對手論點的真假；識破是玩家的事。
* 「對手還有多少牌可打」指他能用來贏的選項：手上還沒打出、也還沒被打掉的謊言＋有利的事實＋撿來的證物；已經站在他鏈上的不算〔R-28〕；周旋改口重提而回手的牌算一張〔V-10〕。對手用撿來的證物駁倒玩家，用的是資訊，不消耗那張牌〔V-09〕。畫面不顯示數量。這個數量 ≤ 2 時觸發事件「選項所剩無幾」（見 8.2）。

### 5.3 回合流程

1. **預兆**：對手亮出這回合準備說的論點（文字）與動作預兆（明示／模糊／偽裝，沿用 v1）。他即將說溜嘴時，預兆只顯示開頭半句或「欲言又止」，不預告內容〔V-02〕。
2. **選擇**：玩家選行動；需要時選證物與說法（或反駁對象）。可在鎖定前佈置援護：每場 1 次（依助手而定）。佈置的那一回合，若玩家被拆穿、被駁倒或反駁落空，亞瑟出面打圓場，該回合的傷害與失守取消；沒有發生這些事則援護白費〔模擬：補定義〕。
3. **揭示與結算**：依對決表（第 6 節）。
4. **心理更新**：依本回合發生的事件與性格表加減三個心理數值，並立刻判定是否越過門檻。自然回落移到下一回合開始時〔R-11〕。
5. **態勢檢查**，依序：破防與失守 → 論破 → 可信度歸零 → 失常反應。對手可信度歸零與論破一樣會進入殘局（7.4）〔R-13〕。

## 6. 行動與對決表

### 6.1 玩家的四個行動【定】

| 行動 | 做什麼 |
| --- | --- |
| 正論（正經議論） | 選一件證物與一個顯示為正論的說法，接上一節 |
| 詭辯 | 選一件證物與一個顯示為詭辯的說法，接上一節；論證較高，但帶裂紋 |
| 反駁 | 選一件證物與說法，打對手的論點。對象二選一：**截斷**（他這回合要說的那句）或**拆台**（他鏈上已經站著的一節） |
| 打迷糊仗 | 說些模糊、古怪、無關緊要的話。不接節 |

正論與詭辯在介面上是同一個「議論」入口：選了證物後，說法清單上每一項都標明是正論或詭辯，以及有無紅色裂紋。

### 6.2 對手的四個行動【提】

| 行動 | 做什麼 | v1 對應 |
| --- | --- | --- |
| 立論 | 打出一張手牌，接上一節 | 主張 |
| 強辯 | 立論的加強版：論證 ×1.25，但被截斷時多受 10 | 猛攻 |
| 反駁 | 打玩家這回合要接的節 | 設陷 |
| 周旋 | 不接節；回復可信度 5，並重新整理手牌（把一張被打掉的謊言改口重提；沿用原牌的可破解清單。被論破毀掉的節不回手）〔R-27〕 | 補強 |

### 6.3 對決表（初值）

列＝玩家，欄＝對手。

| 玩家＼對手 | 立論／強辯 | 反駁 | 周旋 |
| --- | --- | --- | --- |
| **正論** | 雙方各接一節，各自造成論證傷害 | 被擋下：這節沒接上，不受傷，連擊保留。若這個說法的「對手能否駁倒」欄成立，則這節被**駁倒**：受 15，連擊歸零，該說法本場作廢，我方進入失守〔R-05、R-08〕 | 接上一節，造成論證傷害 |
| **詭辯** | 雙方各接一節 | **被拆穿**：這節沒接上，受 25，連擊歸零，紀錄留 1 道裂紋，我方進入失守 | 接上一節 |
| **反駁（截斷）** | 見 6.4。成功：他的節沒接上，他受 20，進入破防 | 互相落空，雙方各 −5 | 落空：我方 −5，下回合對手的立論無法被截斷 |
| **反駁（拆台）** | 見 6.4。成功：移除那一節，他受 10；但他這回合照常接上新的一節 | 拆台照常結算；他的反駁落空 −5 | 拆台照常結算 |
| **打迷糊仗** | 他接上一節，我方只受一半傷害 | **他的反駁落空**：他 −5，進入破防，下回合預兆變為明示 | 僵持：旁觀者不耐，雙方各 −3 |

* 打迷糊仗連續使用第 2 次起，減傷與破防效果取消，並額外 −3（旁觀者不耐）。
* 雙方同一回合可信度都歸零：玩家勝，勝利等級降一級，最低到等級四〔R-23〕。
* v1 的「觀察」取消；它的「減傷」與「看穿下回合預兆」併入打迷糊仗。

### 6.4 反駁的成敗：兩層讀招【定＋提】

反駁用的說法分正論與詭辯，對象分三種：

| 對手的論點 | 用正論反駁 | 用詭辯反駁 |
| --- | --- | --- |
| 謊言 | 該說法在「可破解」清單內 → 成功，乾淨。不在清單內 → 落空：我方 −5，他的節照常接上並造成論證 | 同爭點即成功；紀錄留 1 道裂紋 |
| 有利的事實 | 打不掉。落空：我方 −10，他的節照常接上，但不另外造成論證 | 同爭點即成功；留 1 道裂紋；記 1 次「否定事實」（見第 9、10 節）；對手怒氣上升 |
| 不利的事實（說溜嘴） | 不該打。落空，且錯過接話機會 | 同上，且錯過接話機會 |

* 落空的代價分兩級：讀對他會開口、只是牌不對（−5，但挨他的論證），比打到事實（−10）輕〔R-04〕。
* 所以每回合要讀兩件事：他會不會真的開口，以及他這句話是真是假。
* 【定】用詭辯把對手的事實打掉，可以阻止對手自洽（他的鏈少一節，離論破玩家更遠）。

### 6.5 接話：抓住說溜嘴【提】

* 對手打出不利的事實並成功接上後，下一回合玩家的議論清單多一個選項「抓住他的話」：不需要證物，視為正論，基礎值 18（已含加成，不另外乘），屬於該事實的爭點〔模擬〕。只在下一回合有效。
* 為了讓這個機制用得到，說溜嘴不必等到失常：任一心理數值進入「浮動」段（門檻 − 15 以上）時，對手每次立論有 30% 機率改打不利的事實〔R-18〕。
* 不利的事實接上時不對玩家造成論證〔V-01〕。
* 「抓住他的話」的基礎值 18 只是不再另乘 1.5；連擊、破竹、破防等修正照乘〔V-05〕。
* 那句話同時成為玩家的「已知」資訊，會影響之後各說法顯示為正論或詭辯。

## 7. 論證、主導權與論破

### 7.1 論證傷害（初值）

`論證 ＝ 基礎值 × 連擊倍率 × 態勢修正`

* 基礎值：正論 12、詭辯 16、抓住他的話 18。
* 連擊倍率：1 ＋ 0.25 ×（連擊數 − 1），連擊數最多算到 5（×2.0）。
* 延續加成：這一節與上一節同爭點，或說法之間有劇本標記的「承接」關係 → 再 ×1.2，並播放承接台詞。
* 態勢修正：破竹每層 +10%（最多 3 層）；對手破防中 +25%。各項相乘，以回合開始時的狀態為準〔R-25〕。破防的 +25% 只作用於論證，不作用於截斷 20、拆台 10 這類固定傷害〔R-26〕。
* 對手的論證 ＝ 階段基礎值（前期 20、中期 14、後期 22〔模擬二〕）× 他的連擊倍率（算法同玩家）×（強辯 1.25）〔R-02〕。
* 對手可信度上限：前期約 130～140、中期 190、後期 260、Wolfhart 230〔模擬〕。原則：要高於「達成論破所需回合數 × 平均論證」，論破才會發生在他還有血的時候〔R-01、R-24〕。

### 7.2 態勢（主導權）

| 態勢 | 觸發 | 效果 | 書法大字 |
| --- | --- | --- | --- |
| 破防 | 對手：被截斷、反駁落空、任一心理數值越過門檻的那一回合。持續到下一回合結束 | 對手受到的論證 +25%；可被論破 | 動搖（沿用） |
| 破竹 | 玩家讀對且對手這回合沒有傷到我方：議論接上而對手周旋或反駁落空、截斷成功、打迷糊仗騙到反駁落空，每次 1 層，最多 3 層。互相接上維持層數但不加層；讀錯歸零〔R-09〕 | 每層論證 +10% | 破竹 |
| 困獸 | 對手壓力越過門檻 | 見 8.3 | 困獸 |
| 失守 | 玩家的詭辯被拆穿，或正論被駁倒〔R-08〕 | 持續到玩家下一次讀對為止〔模擬二：只持續一回合時逆論破幾乎不發生〕。「讀對」的定義與破竹加層相同，互相接上不算；所以失守中只有截斷成功或讓他反駁落空才解得開。失守時畫面提示「讀對一次才能站穩」〔V-11〕。期間玩家受到的傷害 +25%，可被逆論破 | 失守 |

### 7.3 論破【定＋提】

* **條件**：對手處於破防，玩家成功接上一節，且接上後鏈長 ≥ 論破門檻（前期 3、中期 4、後期 4；後期設 5 會拖得太長〔模擬〕），且鏈上至少涵蓋 2 個爭點。
* **另一條路（抓漏洞）**：截斷成功時，若打掉的是對手劇本標記的「要害論點」，且對手可信度 ≤ 50% 或正處於破防，直接論破，不看鏈長；否則算一般截斷〔R-19〕。
* **效果**：對手的推理鏈全毀，可信度降到 1 並鎖定，進入**殘局**。播放論破演出（書法大字「論破」）。
* 對手論破玩家（逆論破）條件對稱：玩家失守中，對手接上一節，他的鏈長 ≥ 門檻。玩家可信度降到 1，進入殘局，由玩家打最後一張牌（見 7.5）。
* 同一回合雙方都滿足條件時，以該回合造成論證較高的一方為準，另一方不成立。所以一次只有一方被論破。

### 7.4 殘局：對手的最後一張牌【定＋提】

**何時進入殘局**：對手被論破，或對手可信度將要歸零（不論有沒有論破）。兩者都把他的可信度鎖在 1。玩家身上的把柄一定會在收尾時被檢驗一次，不能靠「不論破、直接打到歸零」躲掉〔R-13〕。模擬證實這條必要：沒有它時，「詭辯截斷＋磨血」完全不必付殘局的代價，後期勝率 86%，高過謹慎打法的 75%〔模擬〕。

**裂紋數 c** ＝ 玩家公開紀錄上的裂紋道數（每個詭辯節 1 道、每次自相矛盾 1 道、每次詭辯反駁 1 道、每次被拆穿 1 道）。不重複計算〔R-16〕。

**對手能否還手**

| 情況 | 結果 |
| --- | --- |
| 對手罪惡感越過門檻 | 放棄，不還手 → 勝利 |
| c ＝ 0，且對手沒有撿到證物 | **乾淨**。對手若有劇本指定的殺手鐧，只當作「垂死反撲」的演出：可以截斷；打中只扣玩家 10，不回復對手，也不影響勝利等級〔R-14〕 |
| 其他（c ≥ 1，或對手撿到了證物） | 對手打出最後一張牌 |

**打哪一張**：依性格表的優先順序；預設是撿來的證物 ＞ 劇本殺手鐧 ＞ 改口〔R-03〕。

**殘局回合玩家只有兩個選項**〔R-03〕：

* **截斷**：選證物與說法。說法在那張牌的可破解清單內 → 反擊失敗，勝利。不在清單內 → 視同承受，並額外 −5。
* **承受**。

**最後一張牌打中的效果**

* 玩家紀錄上所有帶裂紋的節被打掉，連擊與破竹歸零〔V-07〕。
* 玩家受傷 ＝ 15 × c〔模擬二：裂紋改看整份公開紀錄後，20 太重〕。
* 用的是玩家留下的證物時再 +10〔模擬二〕；c ＝ 0 時同樣適用（這就是留下證物的代價）〔R-15〕。
* c ＝ 0 但對手有撿來的證物：玩家受 20（＋上一條的 10），對手回復 10%。
* 對手可信度回復到上限的 12% × c（最多 45%），解除鎖定〔模擬〕。
* 玩家可信度因此歸零 → **論敗**（贏了論破卻輸了論戰）。
* 之後論戰照常繼續。對手已無最後一張牌；再次被論破或歸零即結束。

### 7.5 玩家被論破之後

* 玩家可信度鎖在 1。下一回合玩家可以打自己的最後一張牌：一個能駁倒對手鏈上某個謊言的正論（對應 v1 的「絕境重組／反擊論破」）。這是劇本回合，對手不行動〔R-34〕。這張牌若帶紅色裂紋，先回復到 30% 再扣 10〔V-12〕。成功 → 對手該節與其後的節全毀，玩家回復到 30%，論戰繼續。
* 沒有這樣的牌，或讀錯 → 論敗。

### 7.6 勝負

* 任一方可信度歸零即結束【定】。失敗不結束遊戲，影響後續流程與劇情【定，沿用】。
* 勝利分級（影響聲譽、報紙）〔R-31〕：

| 等級 | 條件 |
| --- | --- |
| 一：乾淨論破 | 論破，c ＝ 0，對手無牌可還手（含對手因罪惡感放棄、或殘局截斷成功） |
| 二：論破守成 | 論破，c ≥ 1，但對手放棄，或最後一張牌被截斷 |
| 三：論破後被反擊仍勝 | 最後一張牌打中，之後仍獲勝 |
| 四：未論破而勝 | 把對手磨到歸零，殘局過關。從歸零進入殘局的，不論對手放棄或最後一張牌被截斷，都是等級四 |
| 五：論敗 | 玩家可信度歸零 |

## 8. 對手的心理：壓力、罪惡感、怒氣【定】

### 8.1 基本規則

* 三個數值各 0～100，開場值、門檻、每回合回落量寫在各對手的性格表。
* 畫面上以三條沒有數字的量表呈現在對手身旁【提】；門檻位置不顯示，由對手的表情與姿態變化暗示（平常／浮動／失常三段）。
* 一個動作只觸發一個事件〔R-10〕。截斷謊言算「謊言被打掉」，用詭辯截斷事實算「事實被詭辯打掉」；撿來的證物依它被當成謊言或事實歸類。原本的「立論被截斷」因此永遠不會單獨發生，已刪除〔模擬二〕。
* 心結、弱點、無辜者被牽連這類事件，在說法接上或截斷成功時才觸發；性格表可標註「每場一次」〔R-20〕。
* 同一事件對不同對手的影響可以相反【定】（例：選項所剩無幾，一般人壓力上升，自信型的人壓力下降）。
* 最終 Boss：增量小、門檻高、回落快【定】。

### 8.2 事件清單與預設增量【提】

性格表對每一格填倍率（可為負或零）。下表是倍率為 1 時的增量。

| 事件 | 壓力 | 罪惡感 | 怒氣 |
| --- | --- | --- | --- |
| 謊言被正論打掉 | +20 | +10 | 0 |
| 謊言被詭辯打掉 | +12 | 0 | +12 |
| 事實被詭辯打掉【定】 | +5 | 0 | +20 |
| 自己的反駁落空 | +8 | 0 | +12 |
| 被打迷糊仗 | 0 | 0 | +10 |
| 成功打中玩家（接上、拆穿） | −10 | 0 | −8 |
| 選項所剩無幾 | +20 | 0 | 0 |
| 被戳中個人弱點（心理牌、特定說法） | 依該牌的「心理作用」欄 | 同左 | 同左 |
| 無辜者被牽連（特定劇情節點、特定說法） | 0 | +20 | 0 |
| 說法觸及他的心結（劇本標記） | +5 | +15 | 0 |
| 玩家公開他的私事 | +10 | 0 | +15 |
| 每回合自然回落 | −3 | −1 | −5 |

### 8.3 越過門檻的失常反應

| 數值 | 類別 | 反應（持續到該數值回落到門檻以下） |
| --- | --- | --- |
| 壓力 | 展現破綻【定】 | 越過的那一回合進入破防，書法大字「困獸」。之後預兆一律明示；下一次立論改打不利的事實（若有）；可信度回復類效果失效 |
| 罪惡感 | 放棄【定】 | 不使用栽贓類的牌；被論破後不打最後一張牌。到達 100：當場自白，論戰以勝利結束（專屬演出） |
| 怒氣 | 錯誤策略【定】 | 行動被強制為強辯或反駁（依性格表二選一的比例），忽略原本的行為表；預兆明示；周旋不可用。期間他的強辯論證 ×1.25（真的比較痛），但更好讀 |

* 心理狀態好（三者都在門檻下，且還有牌可打）時，對手不會打不利的事實【定】。
* 多個數值同時越過時，行動限制以怒氣為準，殘局以罪惡感為準。
* 失常狀態與行為表的規則可以並存：做什麼行動由行為表（或怒氣）決定，打哪張牌由壓力決定。例：困獸中的對手可以用強辯喊出一句不利的事實〔R-17〕。

### 8.4 性格表的格式

每個對手一張：

| 欄位 | 內容 |
| --- | --- |
| 開場值 | 壓力／罪惡感／怒氣 |
| 門檻 | 三個數值各自的門檻 |
| 回落倍率 | 對 8.2 末列的倍率 |
| 事件倍率 | 8.2 每一列 × 三欄的倍率 |
| 個人弱點 | 0～2 項；各自對應的心理牌或說法，以及增量 |
| 失常偏好 | 怒氣失常時強辯：反駁的比例 |
| 最後一張牌 | 有／無；內容；優先順序 |

**行為表的預設優先順序**〔V-03〕：標為「必定」的規則 ＞ 玩家上回合詭辯 → 反駁 ＞ 自己的牌剛被打掉 → 周旋 ＞ 剛打中玩家 → 立論。性格表可以改寫順序。以可信度百分比為條件的規則，不把論破的「鎖在 1」算作觸發；殘局解除鎖定後照常判定〔V-04〕。

性格原型（供數值表展開）：一般人、心虛的初犯、老練的慣犯、自信的專家、易怒的權貴、冷靜的主謀（Wolfhart）。

## 9. 真相與「贏了卻不知道真相」【提】

每場論戰結束時，系統計算**真相度**（不顯示數字）。依**公開紀錄**計算，不看那句話最後是否還站著〔R-12〕：

* 起點 100%。
* 本場說過的每一個真偽為假的說法（接上的、被打掉的、用來反駁的都算）：−15%。
* 每次用詭辯否定事實：−20%。
* 每件與真相有關卻沒帶走的關鍵證物：−10%。

用途：

* 黃金線索（沿用 v1）：真相度 ≥ 70%，且該線索對應的證物至少用過一次真的說法〔R-33〕。
* 亞瑟結案筆記的版本：≥ 70% 知道全貌；40～69% 只知道一半；＜ 40% 抓對人但理由是錯的。敗北時真相度只用來決定筆記版本〔R-32〕。
* True End 條件沿用 v1（全部關鍵推理正確且全部勝利），「推理正確」改以真相度 ≥ 70% 判定。

製作量（助手 B 實測 Ch.2）：照上表逐項寫約 150 句台詞、100 列表格，是 v1 的 2.5 倍。採用下列共用方式後，每場約 90～100 句、70 列：
