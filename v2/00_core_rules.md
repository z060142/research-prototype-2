* 白板（討論紀錄）：https://claude.ai/artifact/B6Lad6bcG9UYmVkV7P7iTr

* 標記：**【定】** = 使用者已確認；**【提】** = Claude 的提案，待使用者確認；數值一律是初值，由 `v2/01_numbers.md` 定案。

## 1. 設計目標

1. 【定】同一件證物可以有不同詮釋；玩家怎麼使用證物，決定他能提出什麼推理。
2. 【定】贏不代表掌握真相；可以靠詭辯勉強獲勝，也可能贏得不體面而失去信任。
3. 【定】這些取捨發生在每一回合的出牌裡，不是結算畫面才告知。
4. 【定】推理鏈逐回合建立，每回合只有一個明確的論證主體；不再預先組鏈、一次打出一段。
5. 【定】雙方同時決定行動，再結算。
6. 【定】論破是攻防的高潮，不是勝利；一次只有一方被論破；論破後對手可能還有最後一張牌。
7. 【定】每場論戰依案件專門設計，不要求系統對所有組合都有敘事反應。

## 3. 證物與說法

### 3.1 說法的資料

每個說法有下列欄位：

| 欄位 | 內容 |
| --- | --- |
| 文本 | Sherefox 說出這個說法的台詞（主張句） |
| 爭點 | 屬於哪一個爭點 |
| 相容條件 | 一份「與此說法衝突的資訊」清單（證物、鑑定結果、觀察、對手說溜嘴的話） |
| 真偽 | 這個說法是否符合真相。對玩家隱藏 |
| 互斥 | 與哪些其他說法互相矛盾 |
| 可破解 | 這個說法能駁倒對手的哪些論點 |
| 心理作用 | （選填）對特定對手的壓力／罪惡感／怒氣加減 |
| 私事 | （選填）是否公開了當事人不必被公開的私事 |

### 3.2 正論與詭辯由「玩家知道什麼」決定【提】

* 說法的衝突清單中，沒有任何一項是玩家已知的 → 顯示為**正論**。
* 有任何一項是玩家已知的 → 顯示為**詭辯**（玩家是明知故說）。
* 「已知」＝玩家帶走的證物、做過的鑑定、看過的觀察、對手在本場公開說過且未被打掉的事實。沒帶走、沒鑑定的不算已知。
* 因此玩家可以誠心打出一個不符合真相的正論。這就是「鏈結實但方向錯」：系統當它是正論，對手也只能用玩家不知道的資訊去打它。
* 一個說法在論戰途中可能由正論變成詭辯（例如對手說溜嘴，玩家因此「知道」了）。已經打出的節不回溯；之後再用才算詭辯。
* 心理牌（例：通靈板）沒有任何正論說法，所有說法都是詭辯【定：通靈板算詭辯】。

### 3.3 詮釋的時機【提】

* 詮釋在論戰中進行：出牌時選證物，再選說法。
* 調查時不做選擇題。證物清單上每件證物可以留一句「私下的看法」（從該證物的說法中擇一，或留空），隨時可改，沒有代價，也沒有效果，只是玩家的筆記；論戰選說法時預設停在這一項。
* 線索板畫面移除。

### 3.4 重複使用與矛盾【提】

* 同一件證物可以重複使用【定】。同一個說法站在鏈上時不能再接一次；被打掉後可以重提（重提的論證 ×0.5）。
* 說法與自己公開紀錄中的某句話互斥時，選項按鈕顯示**紅色裂紋**。可以選，代價：
  * 可信度立即 −10。
  * 舊的那一節若還站著，立刻失效移除。
  * 新的這一節帶 1 道裂紋。
* 不遮蔽矛盾選項。

## 4. 調查（v2 只規定與論戰相接的部分）

1. 【定】每次調查能帶走的證物數量有限。【提】上限＝現場可參戰證物數 − 2（Ch.1 教學章不設限；後期章 − 3）。
2. 【定】沒帶走的證物可能落入對手手中。【提】每件證物另有一欄「對手的用法」；有這一欄且被留下的證物，進入對手的牌庫。對手最多撿 2 件。玩家離開現場前能看到「留下的清單」，不會顯示哪些會被撿。
3. 【提】鑑定（亞瑟的醫療／機械）不改變證物本身，而是讓玩家「知道」更多：鑑定結果會進入說法的相容判斷，可能把一個原本的正論變成詭辯，也會解鎖新的說法。
4. 【定】對手的個人弱點與性格靠調查對手本人、日常相處得知。【提】調查點新增「人物」類：得到的不是證物，是一條人物筆記（弱點或性格線索），不佔攜帶名額。能戳中弱點的道具（心理牌）要佔名額。
5. 【提】防卡關：每場論戰必須保證，任何合法的帶法都至少有一條不靠詭辯的獲勝路線；差別只在漂亮程度（能否乾淨論破、是否拿到黃金線索）。

## 5. 論戰的構成

### 5.1 雙方各有

* 可信度（上限：玩家 100／120／150 依前中後期；對手依數值表）。
* 推理鏈與公開紀錄。
* 連擊數：連續成功接上節的回合數。沒接上（被擋、被打斷、打迷糊仗、反駁）不歸零也不增加；被拆穿或被論破時歸零。【提】
* 對手另有：手牌、三個心理數值、性格表。

### 5.2 對手的手牌【定】

| 類別 | 內容 | 何時打出 |
| --- | --- | --- |
| 謊言 | 與真相不符的論點 | 一般 |
| 有利的事實 | 真的，且對他有利 | 一般 |
| 不利的事實 | 真的，但對他不利 | 只在心理失常，或有利的牌與謊言用盡時 |
| 撿來的證物 | 玩家留下的證物（依「對手的用法」） | 一般；也可留作最後一張牌 |
| 最後一張牌 | 每個對手 0～1 張劇本指定的殺手鐧 | 被論破之後 |

* 系統不標示對手論點的真假；識破是玩家的事。
* 「對手還有多少牌可打」指他能用來贏的選項：還沒被打掉的謊言＋有利的事實＋撿來的證物。畫面不顯示數量。這個數量 ≤ 2 時觸發事件「選項所剩無幾」（見 8.2）。

### 5.3 回合流程

1. **預兆**：對手亮出這回合準備說的論點（文字）與動作預兆（明示／模糊／偽裝，沿用 v1）。
2. **選擇**：玩家選行動；需要時選證物與說法（或反駁對象）。可在鎖定前佈置援護（沿用 v1）。
3. **揭示與結算**：依對決表（第 6 節）。
4. **心理更新**：依本回合發生的事件與性格表加減三個心理數值，再做自然回落。
5. **態勢檢查**：破防、論破、失常反應、勝負。

## 6. 行動與對決表

### 6.1 玩家的四個行動【定】

| 行動 | 做什麼 |
| --- | --- |
| 正論（正經議論） | 選一件證物與一個顯示為正論的說法，接上一節 |
| 詭辯 | 選一件證物與一個顯示為詭辯的說法，接上一節；論證較高，但帶裂紋 |
| 反駁 | 選一件證物與說法，打對手的論點。對象二選一：**截斷**（他這回合要說的那句）或**拆台**（他鏈上已經站著的一節） |
| 打迷糊仗 | 說些模糊、古怪、無關緊要的話。不接節 |

正論與詭辯在介面上是同一個「議論」入口：選了證物後，說法清單上每一項都標明是正論或詭辯，以及有無紅色裂紋。

### 6.2 對手的四個行動【提】

| 行動 | 做什麼 | v1 對應 |
| --- | --- | --- |
| 立論 | 打出一張手牌，接上一節 | 主張 |
| 強辯 | 立論的加強版：論證 ×1.25，但被截斷時多受 10 | 猛攻 |
| 反駁 | 打玩家這回合要接的節 | 設陷 |
| 周旋 | 不接節；回復可信度 5，並重新整理手牌（把一張被打掉的謊言改口重提） | 補強 |

### 6.3 對決表（初值）

列＝玩家，欄＝對手。

| 玩家＼對手 | 立論／強辯 | 反駁 | 周旋 |
| --- | --- | --- | --- |
| **正論** | 雙方各接一節，各自造成論證傷害 | 被擋下：這節沒接上，不受傷，連擊保留。若對手手上有能駁倒這個說法的資訊（玩家不知道的那一項），則這節被駁倒：受 15，該說法本場作廢 | 接上一節，造成論證傷害 |
| **詭辯** | 雙方各接一節 | **被拆穿**：這節沒接上，受 25，連擊歸零，紀錄留 1 道裂紋，我方進入失守 | 接上一節 |
| **反駁（截斷）** | 見 6.4。成功：他的節沒接上，他受 20，進入破防 | 互相落空，雙方各 −5 | 落空：我方 −5，下回合對手的立論無法被截斷 |
| **反駁（拆台）** | 見 6.4。成功：移除那一節，他受 10；但他這回合照常接上新的一節 | 拆台照常結算；他的反駁落空 −5 | 拆台照常結算 |
| **打迷糊仗** | 他接上一節，我方只受一半傷害 | **他的反駁落空**：他 −5，進入破防，下回合預兆變為明示 | 僵持：旁觀者不耐，雙方各 −3 |

* 打迷糊仗連續使用第 2 次起，減傷與破防效果取消，並額外 −3（旁觀者不耐）。
* v1 的「觀察」取消；它的「減傷」與「看穿下回合預兆」併入打迷糊仗。

### 6.4 反駁的成敗：兩層讀招【定＋提】

反駁用的說法分正論與詭辯，對象分三種：

| 對手的論點 | 用正論反駁 | 用詭辯反駁 |
| --- | --- | --- |
| 謊言 | 該說法在「可破解」清單內 → 成功，乾淨 | 同爭點即成功；紀錄留 1 道裂紋 |
| 有利的事實 | 打不掉。落空：我方 −10 | 同爭點即成功；留 1 道裂紋；記 1 次「否定事實」（見第 9、10 節）；對手怒氣上升 |
| 不利的事實（說溜嘴） | 不該打。落空，且錯過接話機會 | 同上，且錯過接話機會 |

* 所以每回合要讀兩件事：他會不會真的開口，以及他這句話是真是假。
* 【定】用詭辯把對手的事實打掉，可以阻止對手自洽（他的鏈少一節，離論破玩家更遠）。

### 6.5 接話：抓住說溜嘴【提】

* 對手打出不利的事實並成功接上後，下一回合玩家的議論清單多一個選項「抓住他的話」：不需要證物，視為正論，論證 ×1.5，屬於該事實的爭點。只在下一回合有效。
* 那句話同時成為玩家的「已知」資訊，會影響之後各說法顯示為正論或詭辯。

## 7. 論證、主導權與論破

### 7.1 論證傷害（初值）

`論證 ＝ 基礎值 × 連擊倍率 × 態勢修正`

* 基礎值：正論 12、詭辯 16、抓住他的話 18。
* 連擊倍率：1 ＋ 0.25 ×（連擊數 − 1），連擊數最多算到 5（×2.0）。
* 延續加成：這一節與上一節同爭點，或說法之間有劇本標記的「承接」關係 → 再 ×1.2，並播放承接台詞。
* 態勢修正：破竹每層 +10%（最多 3 層）；對手破防中 +25%。

### 7.2 態勢（主導權）

| 態勢 | 觸發 | 效果 | 書法大字 |
| --- | --- | --- | --- |
| 破防 | 對手：被截斷、反駁落空、任一心理數值越過門檻的那一回合。持續到下一回合結束 | 對手受到的論證 +25%；可被論破 | 動搖（沿用） |
| 破竹 | 玩家連續讀對（接上、截斷成功、騙到對手落空都算），每次 1 層，最多 3 層；讀錯歸零 | 每層論證 +10% | 破竹 |
| 困獸 | 對手壓力越過門檻 | 見 8.3 | 困獸 |
| 失守 | 玩家被拆穿或被截斷 | 下一回合玩家受到的傷害 +25%，可被逆論破 | 失守 |

### 7.3 論破【定＋提】

* **條件**：對手處於破防，玩家成功接上一節，且接上後鏈長 ≥ 論破門檻（前期 3、中期 4、後期 5），且鏈上至少涵蓋 2 個爭點。
* **另一條路（抓漏洞）**：截斷成功時，若打掉的是對手劇本標記的「要害論點」，直接論破，不看鏈長。
* **效果**：對手的推理鏈全毀，可信度降到 1 並鎖定，進入**殘局**。播放論破演出（書法大字「論破」）。
* 對手論破玩家（逆論破）條件對稱：玩家失守中，對手接上一節，他的鏈長 ≥ 門檻。玩家可信度降到 1，進入殘局，由玩家打最後一張牌（見 7.5）。
* 同一回合雙方都滿足條件時，以該回合造成論證較高的一方為準，另一方不成立。所以一次只有一方被論破。

### 7.4 殘局：對手的最後一張牌【定＋提】

論破後，計算玩家公開紀錄上的**裂紋數 c**（站著的詭辯節＋帶裂紋的節＋詭辯反駁留下的裂紋）。

對手能否還手：

| 情況 | 結果 |
| --- | --- |
| 對手罪惡感越過門檻 | 放棄。無論 c 多少都不還手 → 勝利 |
| c ＝ 0，且對手沒有撿到證物、沒有劇本指定的最後一張牌 | 無牌可出 → **乾淨論破**，勝利 |
| 其他 | 對手打出最後一張牌（撿來的證物、劇本指定的殺手鐧，或「改口」） |

最後一張牌的效果：

* 玩家紀錄上所有帶裂紋的節被打掉，連擊歸零。
* 玩家受傷 ＝ 15 × c；用的是玩家留下的證物時再 +20。
* 對手可信度回復到上限的 10% × c（最多 40%），解除鎖定。c ＝ 0 但有牌可出時，回復 10%，玩家受 20。
* 玩家可信度因此歸零 → **論敗**（贏了論破卻輸了論戰）。
* 之後論戰照常繼續。對手已無最後一張牌；再次被論破即結束。
* 玩家在殘局回合不是只能看：對手亮出最後一張牌的預兆時，玩家可以選反駁（截斷）。手上有能駁倒這張牌的正論 → 截斷成功，反擊失敗，勝利。這是「留一手」的價值。

### 7.5 玩家被論破之後

* 玩家可信度鎖在 1。下一回合玩家可以打自己的最後一張牌：一個能駁倒對手鏈上某個謊言的正論（對應 v1 的「絕境重組／反擊論破」）。成功 → 對手該節與其後的節全毀，玩家回復到 30%，論戰繼續。
* 沒有這樣的牌，或讀錯 → 論敗。

### 7.6 勝負

* 任一方可信度歸零即結束【定】。失敗不結束遊戲，影響後續流程與劇情【定，沿用】。
* 勝利分級（影響聲譽、報紙、黃金線索）：乾淨論破 ＞ 論破後被反擊但仍獲勝 ＞ 未論破磨到歸零 ＞ 論敗。

## 8. 對手的心理：壓力、罪惡感、怒氣【定】

### 8.1 基本規則

* 三個數值各 0～100，開場值、門檻、每回合回落量寫在各對手的性格表。
* 畫面上以三條沒有數字的量表呈現在對手身旁【提】；門檻位置不顯示，由對手的表情與姿態變化暗示（平常／浮動／失常三段）。
* 同一事件對不同對手的影響可以相反【定】（例：選項所剩無幾，一般人壓力上升，自信型的人壓力下降）。
* 最終 Boss：增量小、門檻高、回落快【定】。

### 8.2 事件清單與預設增量【提】

性格表對每一格填倍率（可為負或零）。下表是倍率為 1 時的增量。

| 事件 | 壓力 | 罪惡感 | 怒氣 |
| --- | --- | --- | --- |
| 謊言被正論打掉 | +15 | +5 | 0 |
| 謊言被詭辯打掉 | +8 | 0 | +10 |
| 事實被詭辯打掉【定】 | +5 | 0 | +20 |
| 立論被截斷 | +12 | 0 | +8 |
| 自己的反駁落空 | +8 | 0 | +12 |
| 被打迷糊仗 | 0 | 0 | +10 |
| 成功打中玩家（接上、拆穿） | −10 | 0 | −8 |
| 選項所剩無幾 | +20 | 0 | 0 |
| 被戳中個人弱點（心理牌、特定說法） | 依該牌的「心理作用」欄 | 同左 | 同左 |
| 無辜者被牽連（特定劇情節點、特定說法） | 0 | +20 | 0 |
| 說法觸及他的心結（劇本標記） | +5 | +15 | 0 |
| 玩家公開他的私事 | +10 | 0 | +15 |
| 每回合自然回落 | −3 | −1 | −5 |

### 8.3 越過門檻的失常反應

| 數值 | 類別 | 反應（持續到該數值回落到門檻以下） |
| --- | --- | --- |
| 壓力 | 展現破綻【定】 | 越過的那一回合進入破防，書法大字「困獸」。之後預兆一律明示；下一次立論改打不利的事實（若有）；可信度回復類效果失效 |
| 罪惡感 | 放棄【定】 | 不使用栽贓類的牌；被論破後不打最後一張牌。到達 100：當場自白，論戰以勝利結束（專屬演出） |
| 怒氣 | 錯誤策略【定】 | 行動被強制為強辯或反駁（依性格表二選一的比例），忽略原本的行為表；預兆明示；周旋不可用。期間他的強辯論證 ×1.25（真的比較痛），但更好讀 |

* 心理狀態好（三者都在門檻下，且還有牌可打）時，對手不會打不利的事實【定】。
* 多個數值同時越過時，行動限制以怒氣為準，殘局以罪惡感為準。

### 8.4 性格表的格式

每個對手一張：

| 欄位 | 內容 |
| --- | --- |
| 開場值 | 壓力／罪惡感／怒氣 |
| 門檻 | 三個數值各自的門檻 |
| 回落倍率 | 對 8.2 末列的倍率 |
| 事件倍率 | 8.2 每一列 × 三欄的倍率 |
| 個人弱點 | 0～2 項；各自對應的心理牌或說法，以及增量 |
| 失常偏好 | 怒氣失常時強辯：反駁的比例 |
| 最後一張牌 | 有／無；內容 |

性格原型（供數值表展開）：一般人、心虛的初犯、老練的慣犯、自信的專家、易怒的權貴、冷靜的主謀（Wolfhart）。

## 9. 真相與「贏了卻不知道真相」【提】

每場論戰結束時，系統計算**真相度**（不顯示數字）：

* 起點 100%。
* 玩家鏈上每個站著但真偽為假的節：−15%。
* 每次用詭辯否定事實：−20%。
* 每件與真相有關卻沒帶走的關鍵證物：−10%。

用途：

* 決定是否取得該章的黃金線索（沿用 v1：需要推理正確；門檻 70%）。
* 決定亞瑟結案筆記的版本（知道全貌／只知道一半／抓對人但理由是錯的）。
* True End 條件沿用 v1（全部關鍵推理正確且全部勝利），「推理正確」改以真相度 ≥ 70% 判定。

## 10. 社會聲譽【定＋提】

* 跨章隱藏數值 0～100，開場 50。取代 v1 的惡名值。警督信任度改稱「警督的好感」，與其他角色的好感並列，仍是角色個別數值。
* 每場論戰結束時結算：

| 項目 | 聲譽 |
| --- | --- |
| 乾淨論破 | +6 |
| 論破後被反擊但仍獲勝 | +3 |
| 未論破而獲勝 | +1 |
| 論敗 | −4 |
| 紀錄上每道裂紋 | −1（最多 −5） |
| 每次公開私事（「私事」欄的說法） | −3，且當事人好感 −1【定：內褲的例子】 |
| 使用心理牌 | −2 |
| 打迷糊仗 3 次以上 | −1 |
| 否定事實 | 每次 −2 |

* 效果：下一場論戰的起始可信度 ＋（聲譽 − 50）÷ 5，範圍 −10～+10。【提：先用直接加減血量；副血條留待討論】
* 玩家感受聲譽的途徑：章末報紙的標題與措辭分三檔（體面／普通／難看），旁觀者與日常場景的台詞變化。

## 12. 尚未討論、不在本檔範圍

* 擴大蒐證玩法（使用者提出，尚未討論）。
* 劇情調整（故事先不大改，系統完成後再說）。
* 日常片段的份量與互動形式。
* 聲譽是否改用副血條。
* 攜帶上限的確切數字、對手撿證物的規則細節。
