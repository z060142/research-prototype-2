# v2 示範關卡：大綱（草案 0.1）

* 用途：交給遊戲製作 session 做 demo，展現 v2 在一個章節中的完整玩法。
* 定位：當作玩家已經玩過前面的關卡、後面還有關卡的中期章節。**這一章不會放進完整的遊戲**，所以不碰主線陰謀鏈，不出現 Wolfhart，不產生黃金線索。
* 狀態：本檔只有案件大綱。資料表（說法、手牌、性格表、台詞、數值）要等 `00_core_rules.md` 依助手 A、B 的回報定稿後，寫在 `11_demo_chapter.md`。

## 案件：《降靈會上消失的遺囑》

**一句話**：富孀家的降靈會熄燈三分鐘，亡夫剛被找到的遺囑附錄從上鎖的黃銅筒裡消失；警督當場抓了靈媒。

**為什麼選這個題材**

* 直接用上使用者舉的例子：對手怕鬼，玩家帶通靈板，在論戰中拿出來。
* 維多利亞時代的降靈會熱潮，配蒸氣龐克道具（蒸汽靈應盤、氣動敲桌機關）。
* 一個案子裡自然出現 v2 要展示的每一種牌：謊言、對對手有利的事實、說溜嘴、私事、心理牌、被留下的證物。

## 人物

| 人物 | 身分 | 在本章的作用 |
| --- | --- | --- |
| Sherefox、亞瑟、巴斯克維爾警督 | 常駐 | 沿用；亞瑟提供機械鑑定，警督開場誤抓靈媒 |
| 海德太太 | 富孀，委託人 | 旁觀者兼當事人；私事被公開時好感下降 |
| 塞德里克・海德 | 亡夫的姪子，舊遺囑的繼承人 | **論戰對手（犯人）**。表面是嘲笑降靈會的理性派，實際上非常怕鬼 |
| 瑪德琳夫人 | 靈媒 | 被誤抓的人。她的降靈會確實有機關（是騙子），但沒有偷遺囑 |
| 艾琳 | 年輕女僕 | 遺囑附錄的受益人：她是亡夫的私生女。她自己不知道 |

## 真相

1. 遺囑附錄把一半遺產留給艾琳。塞德里克在整理書房時先看到了它。
2. 降靈會熄燈時，塞德里克離開座位，用姑丈的備用鑰匙打開黃銅筒，取走附錄，藏進壁爐的通風閥裡，打算事後燒掉。
3. 他知道靈媒的桌子有機關，打算事後揭穿她，讓所有人相信是她趁亂下手。
4. 他怕鬼的原因：姑丈臨終那晚叫他，他在賭場，沒有回來。

## 三個爭點

| 爭點 | 塞德里克的說法 | 真相 |
| --- | --- | --- |
| 機會：熄燈時誰能動手 | 只有靈媒離開過桌子 | 他也離開過座位 |
| 手法：黃銅筒怎麼被打開 | 靈媒用機關撬開 | 用備用鑰匙打開，筒上沒有撬痕 |
| 動機：誰需要它消失 | 靈媒想勒索海德太太 | 附錄讓他失去一半遺產，而他欠著賭債 |

## 這一章要展示的 v2 玩法

| 玩法 | 在本章怎麼出現 |
| --- | --- |
| 日常片段 | 開場：Sherefox 想用通靈板嚇亞瑟，被房東太太訓了一頓。通靈板因此留在她的包裡 |
| 攜帶上限 | 現場證物多於可帶走的數量；通靈板要佔一個名額 |
| 被留下的證物 | 靈媒袖子裡的暗袋：留下它，塞德里克就會撿去當最後一張牌 |
| 人物筆記 | 調查塞德里克本人（懷錶裡的姑丈照片、他不敢進書房）得知他怕鬼 |
| 鑑定改變「已知」 | 亞瑟鑑定桌子後，「桌子沒有機關」從正論變成詭辯 |
| 對手說事實 | 「那張桌子底下有機關」是真的，而且對他有利。用正論打不掉；用詭辯可以打掉，但離真相更遠 |
| 對手說謊 | 「我整晚沒離開座位」 |
| 說溜嘴 | 壓力過高時：「燈熄的時候我只是去關窗——」 |
| 心理牌 | 通靈板：算詭辯，罪惡感大幅上升，他放棄最後一張牌 |
| 私事與聲譽 | 動機可以用賭債證明（體面），也可以公開艾琳的身世（更強，但海德太太好感下降、聲譽下降） |
| 紅色裂紋 | 先主張「靈媒是清白的」，後來想用「靈媒的機關」當論據時出現裂紋 |
| 論破與殘局 | 乾淨論破；或靠詭辯論破後被暗袋反擊 |
| 贏了卻不知道真相 | 可以把靈媒說成完全清白而獲勝；結案筆記會指出桌子的機關沒有人解釋 |
| 章末報紙 | 依贏法出三種措辭 |

## 章節流程

開場報紙 → 日常（通靈板）→ 事件（降靈會現場，警督抓人）→ 熱身小論戰（糾正警督）→ 蒐證（降靈室、書房、塞德里克本人）→ 整理帶走的證物 → 主論戰（塞德里克）→ 結算 → 章末報紙 → 亞瑟的結案筆記 → 「下一章預告」佔位畫面。

## 給 demo 的前提設定

* 玩家可信度上限 120（中期），社會聲譽開場 50。
* 所有系統一開始就全部開放，不放教學；只在第一次出現新介面時給一行提示。
* 亞瑟的援護、警督的好感沿用，警督好感開場 3。
