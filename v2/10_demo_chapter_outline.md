# v2 示範關卡：大綱（草案 0.2）

* 用途：交給遊戲製作 session 做 demo，展現 v2 在一個章節中的完整玩法。
* 定位：當作玩家已經玩過前面的關卡、後面還有關卡的中期章節。**這一章不會放進完整的遊戲**，所以不碰主線陰謀鏈，不出現 Wolfhart，不產生黃金線索。
* 狀態：本檔只有案件大綱。資料表（說法、手牌、性格表、台詞、數值）要等 `00_core_rules.md` 依助手 A、B 的回報定稿後，寫在 `11_demo_chapter.md`。

## 案件：《守靈夜消失的遺囑》

**一句話**：富商海德先生的守靈夜，煤氣燈熄了三分鐘，他剛被找到的遺囑附錄從上鎖的黃銅筒裡消失；警督當場抓了下午來修過筒鎖的鎖匠。

**題材原則**【定】

* 案件表面上與鬼神無關，不出現靈媒或降靈會。對手怕鬼這件事不能一眼看穿。
* 通靈板是蒐證過程中找到的一件舊東西。亞瑟認為它完全沒用，以為 Sherefox 在蒐集工藝品。
* 它有沒有用，要玩家自己把幾條不起眼的人物筆記連起來才會發現。

## 人物

| 人物 | 身分 | 在本章的作用 |
| --- | --- | --- |
| Sherefox、亞瑟、巴斯克維爾警督 | 常駐 | 沿用；亞瑟提供機械鑑定，警督開場誤抓鎖匠 |
| 海德太太 | 富孀，委託人 | 旁觀者兼當事人；私事被公開時好感下降 |
| 塞德里克・海德 | 亡者的姪子，舊遺囑的繼承人 | **論戰對手（犯人）**。舉止得體的理性派紳士，實際上非常怕鬼 |
| 布里格斯 | 鎖匠 | 被誤抓的人。他下午確實單獨碰過黃銅筒，身上也有萬用鑰匙；他隱瞞了一件與本案無關的小事 |
| 艾琳 | 年輕女僕 | 遺囑附錄的受益人：她是亡者的私生女。她自己不知道 |

## 真相

1. 遺囑附錄把一半遺產留給艾琳。塞德里克在整理書房時先看到了它。
2. 守靈夜，塞德里克到地下室關小煤氣總閥，讓全屋的燈熄滅；趁暗用姑丈的備用鑰匙打開黃銅筒，取走附錄，藏進壁爐的通風閥裡，打算事後燒掉。
3. 他知道鎖匠下午來修過筒鎖，打算讓所有人相信是鎖匠留了一手。
4. 他怕鬼的原因：姑丈臨終那晚叫他，他在賭場，沒有回來。從那之後他不敢單獨進書房，夜裡不熄燈。

## 三個爭點

| 爭點 | 塞德里克的說法 | 真相 |
| --- | --- | --- |
| 機會：熄燈時誰能動手 | 我整晚守在靈柩旁，沒有離開過 | 他去過地下室，也進過書房 |
| 手法：黃銅筒怎麼被打開 | 鎖匠下午修鎖時留了手腳，身上還有萬用鑰匙 | 用備用鑰匙打開；筒上沒有撬痕，鎖匠修的鎖完好 |
| 動機：誰需要它消失 | 鎖匠想拿去勒索海德太太 | 附錄讓他失去一半遺產，而他欠著賭債 |

## 通靈板與「怕鬼」怎麼埋

| 線索 | 在哪裡 | 表面上看起來 |
| --- | --- | --- |
| 通靈板（靈應盤） | 閣樓的舊玩具箱，海德太太年輕時的沙龍遊戲 | 一塊積灰的木板。亞瑟：「這跟案子沒關係吧？妳什麼時候開始收集工藝品了？」佔一個攜帶名額 |
| 人物筆記 1 | 塞德里克的臥室 | 白天也點著的床頭燈，燈油每天添滿 |
| 人物筆記 2 | 與女僕艾琳交談 | 「少爺從上個月起就不肯一個人進書房，要人陪著」 |
| 人物筆記 3 | 靈柩旁 | 他站得離靈柩最遠，而且背對著它 |
| 人物筆記 4（日常片段的伏筆） | 開場日常 | 房東太太講街坊的鬼故事，亞瑟嗤之以鼻，Sherefox 說：「不信的人不怕，怕的人才最嘴硬。」 |

* 三條筆記都不會寫出「他怕鬼」。玩家把它們連起來，才會覺得那塊木板值得佔一個名額。
* 沒帶通靈板也能贏；它是一條捷徑，不是必要條件。

## 這一章要展示的 v2 玩法

| 玩法 | 在本章怎麼出現 |
| --- | --- |
| 日常片段 | 開場：房東太太的鬼故事、亞瑟與 Sherefox 的鬥嘴。不推動案件，只留一句伏筆 |
| 攜帶上限 | 現場證物多於可帶走的數量；通靈板要佔一個名額，而助手說它沒用 |
| 被留下的證物 | 鎖匠的萬用鑰匙圈：留下它，塞德里克就會撿去當最後一張牌 |
| 人物筆記 | 上表三條，不佔名額 |
| 鑑定改變「已知」 | 亞瑟鑑定筒鎖後，「鎖被動過手腳」從正論變成詭辯；同時解鎖「鎖完好，是用鑰匙開的」 |
| 對手說事實 | 「鎖匠下午單獨碰過那個筒子，身上有萬用鑰匙」是真的，而且對他有利。用正論打不掉；用詭辯可以打掉，但離真相更遠 |
| 對手說謊 | 「我整晚守在靈柩旁，沒有離開過」 |
| 說溜嘴 | 壓力過高時：「地下室那個閥門本來就鬆——」 |
| 心理牌 | 通靈板：算詭辯，罪惡感大幅上升，他放棄最後一張牌 |
| 私事與聲譽 | 動機可以用賭債證明（體面），也可以公開艾琳的身世（更強，但海德太太好感下降、聲譽下降） |
| 紅色裂紋 | 先主張「鎖匠與此事毫無關係」，後來想用「鎖匠隱瞞的那件小事」當論據時出現裂紋 |
| 論破與殘局 | 乾淨論破；或靠詭辯論破後被萬用鑰匙反擊 |
| 贏了卻不知道真相 | 可以把鎖匠說成完全清白而獲勝；結案筆記會指出他隱瞞的事沒有人解釋 |
| 章末報紙 | 依贏法出三種措辭 |

## 章節流程

開場報紙 → 日常（鬼故事）→ 事件（守靈夜現場，警督抓人）→ 熱身小論戰（糾正警督）→ 蒐證（靈堂、書房、地下室、閣樓、塞德里克的臥室）→ 整理帶走的證物 → 主論戰（塞德里克）→ 結算 → 章末報紙 → 亞瑟的結案筆記 → 「下一章預告」佔位畫面。

## 給 demo 的前提設定

* 玩家可信度上限 120（中期），社會聲譽開場 50。
* 所有系統一開始就全部開放，不放教學；只在第一次出現新介面時給一行提示。
* 亞瑟的援護、警督的好感沿用，警督好感開場 3。
