# 論戰數值總表・平衡驗算・用語表

> 本文件涵蓋全 15 案的論戰數值、逐回合平衡驗算與用語表。標「＊」或「（原 X）」者為本文件依驗算新增或修正的數值，其餘為既定數值。

## 一、通用規則與數值

| 項目 | 數值 |
|---|---|
| 傷害公式 | `10 × (1 + 0.5×實證連結數 + 0.8×詭辯連結數) × 動搖倍率` |
| 推理鏈長度 | 2～5 張（1～4 條連結） |
| 動搖倍率 | 1.5（Ch.10 無弱點鏈為 3.0）；未動搖為 1.0 |
| 對手一般反擊 | `10 + 3 × 回合結束時剩餘節點數`（10～22） |
| 主張節點 | 各案上限 2～4。每回合對手重述主張：上回合剩餘節點 +1，不超過上限；第 1 回合與論破後的新階段從上限開始 |
| 節點移除 | 鏈中含某節點的破解證物即移除該節點；4 張以上的鏈最多移除 2 個；沒命中破解證物的鏈照常造成傷害但不移除節點；論破清空所有節點 |
| 詭辯弱點被擊中 | 25，並打斷該條虛線（＊下一條鏈少一條虛線）。每回合可新增 1 條虛線（5 張上限內），但不能補回上回合被打斷的那一條 |
| 援護 | 每場 1 次，擋下一次弱點反擊 |
| 等待破綻 | 本回合不出牌，自損 10；對手多 1 個脆弱節點（醜聞證物命中時自動移除），或下回合醜聞證物必中（對庇護者型見下方規則） |
| 玩家主導權 | 前期 100／中期 120／後期 150（節點規則定案後反擊降低，撤回先前 140／180 的提案） |
| 動搖觸發 | 醜聞類證物命中，或單次 4 張以上連鎖 |
| ＊破防線 | 4 張以上連鎖觸發動搖的條件：中期須對手 ≤ 60%、後期須 ≤ 50%（醜聞證物與黃金線索不受限） |
| ＊動搖持續 | 2 回合，觸發當回合算第 1 回合：觸發那一擊不加成，下一回合的攻擊 ×1.5，論破也須在下一回合打出；論破後對手維持動搖到論戰結束 |
| 論破效果 | 扣對手最大主導權 前期 70%／中期 75%／後期 80%；不足則鎖在 1，進入尾聲；對手維持動搖 |
| 尾聲回合 | 前中期 1（對手的反撲或換說詞在論破當回合的反擊中出現）／後期 2（Ch.12 為 1） |
| 尾聲應對錯誤 | 每答錯 1 次，玩家固定 −30；若尾聲回合用完仍未達成收尾條件，論破作廢：對手回到最大主導權 25%，本場論戰剩餘部分的論破門檻 +1 張 |
| 證物重複使用 | 同一場論戰中，證物可重複出示 |
| 等待破綻（庇護者） | 對庇護者型對手時機正確時，該回合不受反擊（只承受自損 10） |
| 逆・論破 | 限維多與 Wolfhart，每場 1 次。＊觸發：玩家單條鏈含 3 條以上詭辯、援護已用完、弱點被擊中。效果：玩家扣最大主導權 70%／75%／80%（不足鎖 1），下一回合觸發狐耳直覺。Ch.12 論破當回合另有劇本必定觸發的逆・論破（玩家鎖 1，不佔每場 1 次） |
| 狐耳直覺（反擊論破） | 對手的核心反駁證物加入玩家線索板；＊玩家當回合的鏈須符合本章論破門檻（免動搖條件），否則反擊失敗 |
| 惡名值 | ＊每次詭辯被拆穿 +1；單章 ≥ 3 視為高惡名，下一章警督信任度 −1 級 |

## 三、平衡驗算

### 驗算假設

* 目標回合數以**全實證**（設計上的正確打法）判定；混合與全詭辯用來確認風險是否合理。
* 鏈長：前期 3 張、中期 4 張、後期 5 張。混合鏈＝一半連結為詭辯；中期論破那一回合改出 3 張無弱點鏈（中期論破需無弱點）。
* 前期第 2 回合打出醜聞證物觸發動搖（Ch.2 不開放）。Ch.5 第 1 回合使用等待破綻。Ch.12 自第 2 回合起可用黃金線索觸發動搖。
* 不計漏撿證物、9-1【警督信物】放水與 Ch.8 漏找異樣；這些只會讓實際戰局更難或更易，不影響基準。
* 維多（Ch.4、Ch.7、9-3）與 Wolfhart（Ch.12）依規則發動逆・論破；玩家下一回合嘗試反擊論破。
* 尾聲中對手反撲或換說詞，主導權鎖在 1，直到尾聲最後一回合才收尾。驗算假設尾聲應對全部正確；每答錯 1 次，玩家剩餘主導權再 −30。
* 證物可重複使用，因此每回合都能出同一種鏈長。
* 節點移除：全實證鏈每回合移除 1 個節點（4 張以上移除 2 個）；混合鏈的實證段移除 1 個；全詭辯鏈不含破解證物，不移除節點。
* 「撐住」＝玩家只挨打不出手時能撐的回合數（全實證／含詭辯）。

## 四、用語表

| 用語 | 說明 |
|---|---|
| 主導權 | 論戰血條；歸零代表聽眾或當事人的心理防線完全倒向另一方。 |
| 主張節點 | 對手主張鏈上的論點；回合結束時剩下幾個，反擊就多 3 點乘以幾；每回合對手會補回 1 個；被破解證物命中即移除。 |
| 破解證物 | 能推翻某個主張節點的證物；鏈中含有它才會移除該節點。 |
| 推理鏈 | 線索板上串起的 2～5 張證物，論戰中一次打出。 |
| 實證連結 | 屬性標籤吻合且歸類理由正確的實線；每條 +0.5 倍率，無弱點。 |
| 詭辯連結 | 擦邊或理由錯誤的虛線；每條 +0.8 倍率，但留下弱點標記。 |
| 無效連結 | 毫無共同標籤，系統禁止連線。 |
| 弱點標記 | 詭辯連結留下的破綻；對手反擊優先打這裡，命中造成 25，且下一條鏈少一條虛線。 |
| 援護 | 亞瑟每場 1 次，替一條詭辯弱點擋下反擊。 |
| 強證據連鎖 | 行動 A：出相連實證打矛盾，剋犯人型。 |
| 等待破綻 | 行動 B：不出牌並自損 10，逼對手多說而露出脆弱節點，剋庇護者型；時機正確時不受反擊。 |
| 詭辯 | 行動 C：硬拉虛線搶血，剋對手偵探，代價是弱點標記。 |
| 動搖 | 破防狀態：持續 2 回合（觸發當回合算第 1 回合），下一回合受到傷害 ×1.5；由醜聞證物、黃金線索或越過破防線的 4 張以上連鎖觸發。 |
| 破防線 | 中後期 4 張以上連鎖能觸發動搖的對手主導權上限（中期 60%、後期 50%）。 |
