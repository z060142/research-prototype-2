## 2. 原文主要毛病與前後對照範例

歸納原文主要有三類問題：

1. **語句殘缺或過度省略，造成語病與語意歧義**：例如缺少受詞（「我方受 {formula} ＝ {dmg}」「他受 10」「打迷糊仗減半」）、缺少動詞或中心語（「我方的鏈 {n} 節」「妳回復到 {hp}」「處於破防」）、缺少量詞或助詞（「共 {c}」「紀錄留 1 道裂紋」）。
2. **偏大陸慣用法或過於隨性的網遊口語**：例如「張了張口」「沒有用上」「打不掉」「被打掉」「打中」「算一般截斷」，在臺灣推理遊戲的系統結算中顯得不夠俐落一致。
3. **英文翻譯腔與量詞搭配生硬**：例如被動句「下回合他的立論無法被截斷」、直譯句「妳現在知道」、以及「一個能駁倒他鏈上某個謊言的正論」中重複「個」字且與「正論」搭配生硬。

### 前後對照範例（三則）

1. **`SYS_D01_FOG_TAKE`**（省略受詞導致歧義）
   - 原文：`他接上一節。打迷糊仗減半：我方 −{dmg} → {hp}。`
   - 新文：`他接上一節。打迷糊仗使傷害減半：我方 −{dmg} → {hp}。`
   - 說明：原文「打迷糊仗減半」容易誤讀為「打迷糊仗的效果減半」，補上「使傷害」後語意明確。

2. **`SYS_D01_LASTCARD_REMOVE`**（網遊口語／大陸用語感）
   - 原文：`我方紀錄上帶裂紋的 {n} 節被打掉，連擊與破竹歸零。`
   - 新文：`我方紀錄上帶有裂紋的 {n} 節遭擊破，連擊與破竹歸零。`
   - 說明：「被打掉」改為「遭擊破」更貼合推理論戰語境，補「有」字也讓句讀更順暢。

3. **`SYS_D01_REVERSE`**（翻譯腔與量詞累贅）
   - 原文：`逆論破！妳的可信度降到 1。下一回合，妳可以打出自己的最後一張牌：一個能駁倒他鏈上某個謊言的正論。`
   - 新文：`逆論破！妳的可信度降至 1。下一回合，妳可以打出自己的最後一張牌：能駁倒他鏈上任一謊言的正論。`
   - 說明：刪去冗餘且偏翻譯腔的「一個……某個……」，改以「任一」精準表達，並將「降到」統一為較正式的「降至」。

## 3. 不確定、建議人工再看的列

- **`SYS_D01_STALL_HEAL`**（`{name}周旋回復 5，{hp_before} → {hp_after}。`）：目前未改。「周旋回復 5」四字連讀略擠，不確定是否需加逗號改為「{name}周旋，回復 5，…」，因屬固定數值結算格式先保留。
- **`SYS_D01_LASTCARD_HIT`、`SYS_D01_LASTCARD_NOHEAL`、`SYS_D01_DISMANTLE`**：這三則原文僅寫「我方受 …」「他受 10」，屬缺受詞語病，因此參考 `SYS_D01_COVER` 的用詞補上「傷害」（「我方受到傷害 …」「造成 10 傷害」）。因遊戲其他結算句多用「論證」稱呼扣血值，建議人工確認此處使用「傷害」是否與 UI 術語一致。
- **`SYS_D01_SLIP_NODMG`**（`不利的事實接上時不造成論證，我方維持 {hp_p}。`）：目前未改。「不造成論證」讀起來略生硬，但「論證」是系統保留術語（見 `chapter_reference.md` 第 0.1 節），故未改動，建議人工確認。
- **`SYS_D01_PRIVATE`**（`（公開私事：社會聲譽 −3，{person}好感 −1）`）：目前未改。同類型的全形括號說明 `SYS_D01_KEY_NORMAL`、`SYS_D01_PSYCH_NOTE` 皆有句號「。」，本則無句號，不確定是否為刻意排版，先保留原樣。
- **`SYS_D01_KEY_BREAK`**（`截斷要害論點，且{name}處於破防狀態——論破！`）：因屬論破宣判句，保留了「——」破折號的節奏感；另本則涉及下方規則矛盾，建議人工一併檢視。

## 4. 發現的原文事實／規則矛盾（僅回報，未改動事實）

1. **`SYS_D01_KEY_BREAK` 遺漏「可信度 ≤ 50%」的論破條件（與 `chapter_reference.md` 第 1.4 節及 `SYS_D01_KEY_NORMAL` 矛盾）**
   - `chapter_reference.md` 第 1.4 節明定要害論點直接論破的條件為「截斷成功且他可信度 **≤ 50% 或破防中**」，`SYS_D01_KEY_NORMAL` 亦寫「他的可信度高於 50% 且原本未破防，視為一般截斷」。
   - 然而 `SYS_D01_KEY_BREAK` 卻寫死為「截斷要害論點，且{name}處於破防——論破！」。若玩家在對手可信度 ≤ 50% 但**未處於破防**時截斷要害論點觸發論破，此系統訊息會顯示與實際局面不符的狀態。

2. **`SYS_D01_MISS_WRONG` 與 `SYS_D01_MISS_FACT` 結算文字相同，但實際規則不同（對照 `chapter_reference.md` 第 0.1 節）**
   - `chapter_reference.md` 第 0.1 節規定：「截斷事實 −10（他的節照接，**不另外造成論證**）；截斷謊言但說法不在清單 −5（他的節照接**並造成論證**）」。
   - 但 `SYS_D01_MISS_FACT` 與 `SYS_D01_MISS_WRONG` 皆只寫「他的論點照常接上。」，且 `SYS_D01_MISS_WRONG` 沒有呈現對手立論額外造成的論證數值或扣血變化（僅顯示 `我方 −5 → {hp}`），兩則無法區分是否有額外傷害。

3. **`SYS_D01_REVERSE` 漏寫「連擊歸零」（對照 `chapter_reference.md` 路線 D 第 7 回合示範）**
   - 路線 D 第 7 回合示範（第 1531 行）寫「逆論破！妳的可信度降到 1**，連擊歸零**。……」，結算表也將玩家連擊由 2 歸零；但 `SYS_D01_REVERSE`（及第 12.0 節樣板）未寫「連擊歸零」。

4. **`SYS_D01_LASTCARD_HIT` 與 `chapter_reference.md` 第 0.1 節的回復算式表述略有出入**
   - 第 0.1 節寫「對手**回復上限的** 12% × c」（字面意為加上該數值，路線 C 原本鎖定在 1，加上 230 × 36% 應為 83.8），而 `SYS_D01_LASTCARD_HIT`（及路線 C 實際結算 82.8）寫「回復到上限的 {pct}%（{hp_o}）」（直接設為上限的 36%，即 82.8）。
