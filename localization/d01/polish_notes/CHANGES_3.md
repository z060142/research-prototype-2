## 2. 原文主要毛病與改寫範例

1. **對仗金句、格言式收尾與重複排比**：角色開口或筆記收尾偏像網文刻意寫出的金句，不夠自然口語。
2. **濫用「……」製造戲劇停頓**：多處語句並未被中斷或說不下去，卻在句中硬插刪節號（如 `S08_L001`、`L004`、`L009`、`L012`、`S10_L006`）。
3. **翻譯腔、書面語與大陸新聞用語混入**：例如報紙標題用「告破」（臺灣新聞慣用「偵破」）、內文「本報訊，」未與 `1_story_S01-S04.txt` 的「本報訊：」統一、出現易誤讀的「依舊遺囑」、筆記中出現「被說成了它本來不是的樣子」「我很確定。我也很確定」等生硬句式，以及未統一使用證物名稱「黃銅文件筒」。

## 4. 發現的原文事實矛盾（僅回報，未更動事實）

1. **`SCR_D01_S10_L002` 與 `SCR_D01_S10_L007` 直接矛盾（高真相度且未說出 07A／07B 的路線）**
   - 依 `chapter_reference.md`，真相度 ≥ 70% 會播放「知道全貌」（包含 `S10_L002`：「附記：鎖匠布里格斯那晚是回來見廚娘瑪莎的。海德太太說，家規要改了。」）。
   - 然而在未於論戰中使用 `07A`、`07B` 的路線（例如示範路線 B，真相度 85%），`S08_L004`～`L005` 不會觸發，布里格斯未解釋即離開，且系統會附加 `S10_L007`（「還有一件事沒有人解釋：布里格斯那晚為什麼會在屋裡？……我們沒有問。」），導致同一篇結案筆記前後直接矛盾。

2. **`SCR_D01_S09_L002` 與案件真相／手法細節有三處出入**
   - **動機**：「為**掩飾**鉅額賭債」與真相不符——遺囑附錄並未揭露賭債，塞德里克偷附錄是為了避免失去一半遺產、以償還四百鎊賭債，而非「掩飾」賭債。
   - **手法**：「**關閉**煤氣總閥」（另 `SCR_D01_S10_L004` 寫「他關掉了燈」）與真相及 `S04`／`S10_L001` 強調的「**關小**煤氣總閥」不同。真相中是關小至剩一點藍光，才能在三分鐘後轉開時讓全屋煤氣燈同時重亮；若完全關閉，燈熄後不會自行復燃。
   - **證物狀態**：「於書房壁爐中**完好**尋回」與 `SCR_D01_S07_L012`「拉出一卷**燻黑了邊的紙**」略有出入（不過可視為報紙指內容完好未遭焚毀）。

3. **`SCR_D01_S10_L009` 時間線前後衝突**
   - 原文寫「鎖匠**今天**被移送了。附錄**那天晚上**就燒掉了，我很確定。」
   - 依 `S07_L017`～`L019`，敗北發生在守靈夜隔天中午，塞德里克於論戰「當天晚上」才燒掉附錄。若筆記寫於論戰當天（「今天」移送），就不可能用過去式稱附錄「那天晚上」已燒掉（否則會指向守靈當晚，與「附錄原藏在壁爐通風閥裡、敗北當晚才冒煙燒掉」衝突）；若筆記寫於更隔日（正式移送當日），以「那天晚上」指稱昨晚亦不自然。

4. **`SCR_D01_S08_L011`～`L012` 敗北結算台詞假設了特定遊玩狀態**
   - `L011`（「如果我把那個筒子拆開看就好了」）假設未鑑定黃銅文件筒，`L012`（「是我留下了不該留的東西」）假設留了可被對手利用的證物；但在 `chapter_reference.md` 中兩句是所有 `〔敗北〕` 共用，若玩家有鑑定文件筒或未留下可撿證物卻仍論敗，會與實際經過矛盾。

5. **`SCR_D01_S10_L008` 條件未排除敗北，可能與 `L009` 衝突**
   - 依 `chapter_reference.md` S10 表格，`L008`（「我們讓他回家了」）的觸發條件僅標註「說過 06B 且真相度 ＜ 70%」，未限定勝利；若於敗北路線（如路線 D）同時滿足條件，會與 `L009`（「鎖匠今天被移送了」）互相矛盾。
